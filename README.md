# ことばの手紙 — 動画版（スマートフォン対応）

写真や言葉を組み合わせ、封筒から現れるアニメーション付きの手紙動画を作るWebアプリです。

## 公開内容

- 写真とメッセージは利用者の端末内で処理し、サーバーへ送信しません。
- アカウントや保存用バックエンドはありません。
- 指定フォントはGoogle Fontsから読み込みます。初回の読み込みにはインターネット接続が必要です。オフラインでは端末の代替フォントになります。
- 一度サイトを開くと、アプリ本体はService Workerのキャッシュからオフラインでも起動できます。

## GitHub Pagesへの配置

1. このフォルダー内の全ファイルを、新しいGitHubリポジトリのルートへアップロードします。
2. GitHubの **Settings → Pages** を開き、**Deploy from a branch**、公開ブランチ、**/(root)** を選びます。
3. 発行されたHTTPSのサイトURLを、スマートフォンで一度開きます。オフライン利用の準備には初回アクセス時の通信が必要です。

## ホーム画面への追加

- **iPhone**：Safariでサイトを開き、共有ボタン → **ホーム画面に追加** → **Webアプリとして開く** を有効にして追加します。
- **Android**：Chromeでサイトを開き、メニュー → **アプリをインストール**（表示によっては「ホーム画面に追加」）を選びます。
